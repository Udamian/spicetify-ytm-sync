YTM Sync
========

Keeps your Spotify Liked Songs or a playlist mirrored, in the same order, to a YouTube Music
playlist.

Install
  1. Install Spicetify first if you have not (https://spicetify.app/docs/getting-started)
     and open Spotify once.
  2. Double-click "Install YTM Sync.cmd" in this folder (unzip the download first).
     It also puts a "Start YTM Sync" shortcut on your Desktop.
  3. Restart Spotify and open "YTM Sync" in the left sidebar. Follow the steps there.
     To pair, type "YTM Sync Companion" in the Windows search and type the code it shows.

The helper app starts by itself when you sign in to Windows. If you stopped it, start it again
with the "Start YTM Sync" shortcut on the Desktop (or "YTM Sync Companion" in the Windows search)
and press "Try again" on the YTM Sync page.

Windows may warn that the program is from an unknown publisher (it is not code-signed yet).
Choose "More info" and then "Run anyway".

Update
  Download the new release and double-click "Install YTM Sync.cmd" again.

Uninstall
  Double-click "Uninstall YTM Sync.cmd". Your YouTube Music session and copy progress are kept.
  To delete them too, open a terminal in this folder and run:  ytm-sync.exe uninstall --purge

More: https://github.com/Udamian/spicetify-ytm-sync
